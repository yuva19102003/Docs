# DigitalOcean Monitoring

Built-in monitoring, metrics, and alerting for all resources.

## Features
- Resource metrics
- Custom alerts
- Uptime monitoring
- Log aggregation
- Performance insights

## Documentation
- [Monitoring Overview](./0-MONITORING-OVERVIEW.md)

## Quick Start
```bash
# Enable monitoring on Droplet
doctl compute droplet-action enable-monitoring <droplet-id>

# View metrics via control panel
# Droplets → Select Droplet → Graphs
```
