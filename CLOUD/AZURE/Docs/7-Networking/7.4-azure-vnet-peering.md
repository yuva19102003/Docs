# 4️⃣ VNet Peering

## 🔹 Definition

![Image](https://learn.microsoft.com/en-us/azure/virtual-network/media/virtual-networks-peering-overview/local-or-remote-gateway-in-peered-virual-network.png)


**VNet Peering** connects **two VNets privately** using Azure backbone.

* No VPN
* Low latency
* CIDRs must not overlap

### When to use

* App VNet ↔ DB VNet
* Hub ↔ Spoke communication

---

## 🔧 Azure CLI

```bash
az network vnet peering create \
  --resource-group rg-vnet-demo \
  --vnet-name vnet-main \
  --name peer-to-backend \
  --remote-vnet vnet-backend \
  --allow-vnet-access
```

---

## 🖥️ Azure Portal Flow

```
Portal → VNet → Peerings → Add
→ Select Remote VNet
→ Enable Access
```

---

## 📦 Example

```
VNet-A ↔ VNet-B
Private IP → Private IP
```

✔ No internet
✔ No gateway
