

# 2️⃣ Azure Firewall

## 🔹 Definition

![Image](https://learn.microsoft.com/en-us/azure/firewall/media/features-by-sku/firewall-overview.png)


**Azure Firewall** is a **managed, stateful, Layer 7 firewall**.

* Central traffic inspection
* Application & network rules
* Used in **Hub-Spoke architectures**

### When to use

* Enterprise security
* Full traffic control
* Regulatory compliance

---

## 🔧 Azure CLI (Basic)

```bash
az network firewall create \
  --resource-group rg-vnet-demo \
  --name az-firewall \
  --vnet-name vnet-hub
```

Create rule:

```bash
az network firewall network-rule create \
  --resource-group rg-vnet-demo \
  --firewall-name az-firewall \
  --collection-name allow-web \
  --name allow-http \
  --protocols TCP \
  --destination-ports 80 443 \
  --action Allow \
  --priority 100
```
