# ✅ End-to-End Detailed Tutorial

## Azure Front Door CDN for Blob Assets (Terraform + Architecture)

---

# 🎯 Problem Statement

You have a website hosted in:

✅ Azure App Service

Your website contains assets like:

* Images (`.png`, `.jpg`, `.webp`)
* Videos (`.mp4`)
* CSS / JS bundles

Right now, these assets may be served from:

* App Service itself
  or
* Direct Blob URL

This causes problems:

❌ Slow loading for users far away
❌ App Service bandwidth cost increases
❌ No global caching
❌ Blob direct access is not optimized

---

# ✅ Solution

Use this architecture:

* Store assets in Blob Storage
* Put Azure Front Door in front of Blob
* Front Door acts like a CDN

---

# 🌍 Architecture Workflow Diagram

```
User Browser
     |
     | 1. Opens Website
     v
Azure App Service (Frontend)
     |
     | 2. Asset Request (Image/Video)
     |    https://cdn.mysite.com/logo.png
     v
Azure Front Door (Global Edge CDN)
     |
     | 3. Checks Cache at nearest Edge
     |
     |    If Cached → Return instantly
     |    If Not Cached → Fetch from Origin
     v
Azure Blob Storage (Assets Container)
     |
     | 4. Returns Asset File
     v
Front Door caches it globally
     |
     v
User receives asset faster next time
```

---

# ✅ Key Concept

Azure Front Door works exactly like AWS CloudFront:

| AWS              | Azure                   |
| ---------------- | ----------------------- |
| CloudFront CDN   | Azure Front Door        |
| S3 Bucket Origin | Blob Storage Origin     |
| Edge Locations   | Microsoft Global POPs   |
| Cache Rules      | Front Door Rules Engine |
| WAF              | Front Door WAF          |

---

---

# 🔥 Why Not Serve Assets from App Service?

App Service is designed for:

* Running backend/frontend code
* Serving HTML/API responses

But not for heavy assets.

### If you serve videos/images from App Service:

* App Service becomes slow
* Scaling cost increases
* No edge caching

So best practice:

✅ App Service for compute
✅ Blob + CDN for static files

# 2️⃣ storage.tf

## Blob Storage for Assets

---

## Storage Account

```hcl
resource "azurerm_storage_account" "assets" {
  name                     = var.storage_account_name
  resource_group_name      = azurerm_resource_group.rg.name
  location                 = azurerm_resource_group.rg.location

  account_tier             = "Standard"
  account_replication_type = "LRS"

  allow_blob_public_access = true
}
```

### Explanation

Storage Account is the parent resource for:

* Blob containers
* Files
* Queues
* Tables

Important settings:

* **Standard** → cheap, best for assets
* **LRS** → locally redundant storage
* Public access enabled for now (later we secure)

---

## Container Creation

```hcl
resource "azurerm_storage_container" "assets_container" {
  name                  = "assets"
  storage_account_name  = azurerm_storage_account.assets.name
  container_access_type = "blob"
}
```

### Explanation

A container is like an S3 bucket folder.

Example structure:

```
assets/
   images/
   videos/
   css/
```

Blob URL becomes:

```
https://<storage>.blob.core.windows.net/assets/
```

# 3️⃣ frontdoor.tf

## Azure Front Door CDN Setup

Now the CDN part.

---

## ✅ Front Door Profile

```hcl
resource "azurerm_cdn_frontdoor_profile" "cdn_profile" {
  name                = var.frontdoor_profile_name
  resource_group_name = azurerm_resource_group.rg.name

  sku_name = "Standard_AzureFrontDoor"
}
```

### Explanation

A profile is the top-level CDN object.

It contains:

* Endpoints
* Origins
* Routes
* Rules

SKU:

* Standard → enough for most CDN use
* Premium → needed for advanced security + private origins

---

## ✅ Front Door Endpoint

```hcl
resource "azurerm_cdn_frontdoor_endpoint" "cdn_endpoint" {
  name                     = var.frontdoor_endpoint_name
  cdn_frontdoor_profile_id = azurerm_cdn_frontdoor_profile.cdn_profile.id
}
```

### Explanation

This creates the public CDN hostname:

```
https://<endpoint>.azurefd.net
```

This is what users hit globally.

---

## ✅ Origin Group

```hcl
resource "azurerm_cdn_frontdoor_origin_group" "origin_group" {
  name                     = "blob-origin-group"
  cdn_frontdoor_profile_id = azurerm_cdn_frontdoor_profile.cdn_profile.id

  health_probe {
    interval_in_seconds = 120
    path                = "/"
    protocol            = "Https"
    request_type        = "GET"
  }

  load_balancing {
    sample_size                 = 4
    successful_samples_required = 3
  }
}
```

### Explanation

Origin Group is a logical group of origins.

Even if you have only one origin today, later you can add:

* Backup blob
* Multi-region storage

Health probe ensures origin is reachable.

---

## ✅ Origin (Blob Storage)

```hcl
resource "azurerm_cdn_frontdoor_origin" "blob_origin" {
  name                          = "blob-assets-origin"
  cdn_frontdoor_origin_group_id = azurerm_cdn_frontdoor_origin_group.origin_group.id

  enabled            = true
  host_name          = azurerm_storage_account.assets.primary_blob_host
  origin_host_header = azurerm_storage_account.assets.primary_blob_host

  http_port  = 80
  https_port = 443

  priority = 1
  weight   = 100
}
```

### Explanation

Origin = source of truth

Blob is the backend storage.

Front Door will fetch assets from:

```
<storage>.blob.core.windows.net
```

---

## ✅ Route (Caching Rule)

```hcl
resource "azurerm_cdn_frontdoor_route" "cdn_route" {
  name                          = "assets-route"
  cdn_frontdoor_endpoint_id     = azurerm_cdn_frontdoor_endpoint.cdn_endpoint.id
  cdn_frontdoor_origin_group_id = azurerm_cdn_frontdoor_origin_group.origin_group.id

  cdn_frontdoor_origin_ids = [
    azurerm_cdn_frontdoor_origin.blob_origin.id
  ]

  patterns_to_match = ["/*"]

  supported_protocols = ["Http", "Https"]
  forwarding_protocol = "HttpsOnly"

  link_to_default_domain = true

  cache {
    compression_enabled            = true
    query_string_caching_behavior  = "IgnoreQueryString"
  }
}
```

### Explanation

Route defines:

* Which requests should go to blob origin

`patterns_to_match = ["/*"]`

Means:

* All assets will be served

Cache block:

* Compression enabled
* Query string ignored

# ⭐ Production Best Practices

## 1. Use Custom Domain

```
cdn.mysite.com → Front Door
```

## 2. Make Blob Private

Don’t allow direct blob access.

## 3. Enable WAF

Protect against DDoS + attacks.

## 4. Add Cache TTL

Images: 30 days
Videos: 90 days
JS/CSS: 7 days
