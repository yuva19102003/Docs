## 🔹 What is Azure Cosmos DB?

**Azure Cosmos DB** is a **fully managed, globally distributed NoSQL database** designed for:

* Massive scale
* Low latency
* High availability
* Automatic replication
* Multiple data models

---

## 1️⃣ Cosmos DB APIs (VERY IMPORTANT)

| API                | Use Case                    |
| ------------------ | --------------------------- |
| **SQL API (Core)** | Most common, JSON documents |
| MongoDB API        | Mongo-compatible apps       |
| Cassandra API      | Wide-column workloads       |
| Table API          | Key-value                   |
| Gremlin API        | Graph data                  |

👉 **We use SQL API (Core)** — industry standard on Azure.

---

## 2️⃣ Core Concepts (Must Understand)

### 🔹 Account

Top-level Cosmos DB resource.

### 🔹 Database

Logical grouping of containers.

### 🔹 Container

Like a table (stores JSON documents).

### 🔹 Item

Single JSON document.

### 🔹 Partition Key

How data is distributed and scaled.

### 🔹 RU/s (Request Units)

Cost + performance unit.

## 5️⃣ CREATE (Azure CLI)

---

## 5.1 Create Resource Group

```bash
az group create \
  --name azure-solution-architect-labs \
  --location centralindia
```

---

## 5.2 Create Cosmos DB Account (SQL API)

```bash
az cosmosdb create \
  --resource-group azure-solution-architect-labs \
  --name cosmosdb-testing \
  --locations regionName=centralindia failoverPriority=0 \
  --default-consistency-level Session \
  --enable-free-tier true
```

### Explanation

| Option        | Meaning                  |
| ------------- | ------------------------ |
| `--locations` | Region + priority        |
| `Session`     | Best balance consistency |
| Free tier     | 1000 RU/s + 25 GB free   |

## 7️⃣ Create Database & Container

---

## 7.1 Create Database

```bash
az cosmosdb sql database create \
  --account-name cosmosdb-testing \
  --resource-group azure-solution-architect-labs \
  --name appdb
```

---

## 7.2 Create Container

```bash
az cosmosdb sql container create \
  --account-name cosmosdb-testing \
  --resource-group azure-solution-architect-labs \
  --database-name appdb \
  --name users \
  --partition-key-path "/userId" \
  --throughput 400
```

### Why `/userId`?

* Distributes data evenly
* Enables horizontal scaling

---

## 8️⃣ CRUD Operations (Data)

Cosmos DB uses **JSON documents**.

---

## 8.1 Create Item

```bash
az cosmosdb sql item create \
  --account-name cosmosdb-testing \
  --resource-group azure-solution-architect-labs \
  --database-name appdb \
  --container-name users \
  --body '{
    "id": "1",
    "userId": "u100",
    "name": "Yuva",
    "email": "yuva@example.com"
  }'
```

---

## 8.2 View Items

```bash
az cosmosdb sql item list \
  --account-name cosmosdb-testing \
  --resource-group azure-solution-architect-labs \
  --database-name appdb \
  --container-name users
```

---

## 8.3 Query Data (SQL-like)

```bash
az cosmosdb sql query \
  --account-name cosmosdb-testing \
  --resource-group azure-solution-architect-labs \
  --database-name appdb \
  --container-name users \
  --query "SELECT * FROM c WHERE c.userId='u100'"
```

---

## 8.4 Update Item

```bash
az cosmosdb sql item replace \
  --account-name cosmosdb-testing \
  --resource-group azure-solution-architect-labs \
  --database-name appdb \
  --container-name users \
  --item-id "1" \
  --partition-key-value "u100" \
  --body '{
    "id": "1",
    "userId": "u100",
    "name": "Yuva Raj",
    "email": "yuva.raj@example.com"
  }'
```

---

## 8.5 Delete Item

```bash
az cosmosdb sql item delete \
  --account-name cosmosdb-testing \
  --resource-group azure-solution-architect-labs \
  --database-name appdb \
  --container-name users \
  --item-id "1" \
  --partition-key-value "u100"
```
