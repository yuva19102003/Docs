# 1️⃣ CREATE

## 1.1 Create Resource Group

```bash
az group create \
  --name azure-solution-architect-labs \
  --location centralindia
```

---

## 1.2 Create PostgreSQL Flexible Server

```bash
az postgres flexible-server create \
  --resource-group azure-solution-architect-labs \
  --name postgresql-testing \
  --location centralindia \
  --version 18 \
  --tier Burstable \
  --sku-name Standard_B2s \
  --storage-size 32 \
  --admin-user admin123 \
  --admin-password 'Password@123' \
  --backup-retention 7 \
  --high-availability Disabled \
  --geo-redundant-backup Disabled \
  --yes
```

✅ Creates PostgreSQL
✅ Enables backups
✅ SSL enforced by default

# 2️⃣ SHOW / VIEW (Azure CLI)

## 2.1 Show Server Details

```bash
az postgres flexible-server show \
  --resource-group azure-solution-architect-labs \
  --name postgresql-testing
```

---

## 2.2 List All PostgreSQL Servers

```bash
az postgres flexible-server list \
  --resource-group azure-solution-architect-labs \
  --output table
```


---

## 2.4 View Backup Settings

```bash
az postgres flexible-server show \
  --resource-group azure-solution-architect-labs \
  --name postgresql-testing \
  --query backup
```

---

# 3️⃣ PSQL (Database Operations)

## 3.1 Connect to PostgreSQL

```bash
psql "host=postgresql-testing.postgres.database.azure.com \
port=5432 \
dbname=postgres \
user=admin123 \
sslmode=require"
```

## 🔹 DATABASE (View / Create / Delete)

### View Databases

```sql
\l
```

### Create Database

```sql
CREATE DATABASE appdb;
```

### Switch Database

```sql
\c appdb
```

### Delete Database

```sql
DROP DATABASE appdb;
```

---

## 🔹 USERS (View / Create / Delete)

### View Users

```sql
\du
```

### Create User

```sql
CREATE USER appuser WITH PASSWORD 'AppUser@123';
```

### Grant Permissions

```sql
GRANT ALL PRIVILEGES ON DATABASE appdb TO appuser;
```

### Delete User

```sql
DROP USER appuser;
```

---

## 🔹 TABLES (View / Create / Edit / Delete)

### View Tables

```sql
\dt
```

### Create Table

```sql
CREATE TABLE users (
  id SERIAL PRIMARY KEY,
  name TEXT,
  email TEXT UNIQUE,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

### Describe Table

```sql
\d users
```

### Alter Table (Edit)

```sql
ALTER TABLE users ADD COLUMN is_active BOOLEAN DEFAULT true;
```

### Delete Table

```sql
DROP TABLE users;
```

---

## 🔹 DATA (View / Insert / Update / Delete)

### Insert Data

```sql
INSERT INTO users (name, email)
VALUES ('Yuva', 'yuva@example.com');
```

### View Data

```sql
SELECT * FROM users;
```

### Update Data

```sql
UPDATE users
SET name = 'Yuva Raj'
WHERE id = 1;
```

### Delete Data

```sql
DELETE FROM users WHERE id = 1;
```

# 4️⃣ DELETE (Azure Resources)

## 4.1 Delete PostgreSQL Server

```bash
az postgres flexible-server delete \
  --resource-group azure-solution-architect-labs \
  --name postgresql-testing \
  --yes
```

---

## 4.2 Delete Resource Group (Deletes EVERYTHING)

```bash
az group delete \
  --name azure-solution-architect-labs \
  --yes --no-wait
```
