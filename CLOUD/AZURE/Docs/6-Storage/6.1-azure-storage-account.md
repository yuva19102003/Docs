## 1️⃣ What is an Azure Storage Account? (Core Concept)

A **Storage Account** is the **top-level container** in Azure Storage.

Inside ONE storage account, you can have:

* Blob Storage
* File Shares
* Queues
* Tables

👉 **You cannot use Blob/File without a Storage Account**

Think of it like:

```
Storage Account
 ├── Blob Containers
 ├── File Shares
 ├── Queues
 └── Tables
```

---

## 2️⃣ Types of Storage Accounts (Very Important)

| Type                               | Description          | When to use      |
| ---------------------------------- | -------------------- | ---------------- |
| **StorageV2 (General Purpose v2)** | Latest & recommended | 99% of cases     |
| BlobStorage                        | Only blob workloads  | Rare             |
| FileStorage                        | Premium file shares  | High IOPS        |
| BlockBlobStorage                   | Premium blobs        | Media / big data |

✅ **Always choose `StorageV2` unless you have a reason**

---

## 3️⃣ Redundancy Options (Data Safety)

| Option  | Copies   | Region       | Cost     |
| ------- | -------- | ------------ | -------- |
| **LRS** | 3        | Same DC      | 💲       |
| ZRS     | 3        | Same region  | 💲💲     |
| GRS     | 6        | Cross-region | 💲💲💲   |
| RA-GRS  | 6 + read | Cross-region | 💲💲💲💲 |

👉 **Learning / Dev** → `LRS`
👉 **Production critical** → `ZRS / GRS`

---

## 4️⃣ Security Models (How Access Works)

Storage Account supports **3 access methods**:

1. **Access Keys** ❌ (legacy, avoid)
2. **SAS Tokens** ⚠️ (temporary)
3. **Azure AD / Managed Identity** ✅ (best)

📌 Modern best practice:

> **Disable public access + use Managed Identity**

## 5️⃣ Create Storage Account (Azure CLI – Recommended)

### Step 1: Login

```bash
az login
```

### Step 2: Create Resource Group

```bash
az group create \
  --name rg-storage-demo \
  --location eastus
```

### Step 3: Create Storage Account

```bash
STORAGE=staccount$RANDOM

az storage account create \
  --name $STORAGE \
  --resource-group rg-storage-demo \
  --location eastus \
  --sku Standard_LRS \
  --kind StorageV2 \
  --access-tier Hot
```

✅ You have now created a **Storage Account**

---

## 6️⃣ Verify Storage Account

```bash
az storage account show \
  --name $STORAGE \
  --resource-group rg-storage-demo \
  --output table
```

Check:

* Kind → StorageV2
* SKU → Standard_LRS
* Location

---

## 7️⃣ Important Storage Account Settings (Must Know)

### 🔹 1. Access Keys

```bash
az storage account keys list \
  --name $STORAGE \
  --resource-group rg-storage-demo
```

⚠️ **Never hardcode keys in apps**

---

### 🔹 2. Disable Public Network Access (Security)

```bash
az storage account update \
  --name $STORAGE \
  --resource-group rg-storage-demo \
  --public-network-access Disabled
```

✔️ Storage is now **private-only**

---

### 🔹 3. Enable Secure Transfer (HTTPS only)

```bash
az storage account update \
  --name $STORAGE \
  --resource-group rg-storage-demo \
  --https-only true
```

---

### 🔹 4. Minimum TLS Version

```bash
az storage account update \
  --name $STORAGE \
  --resource-group rg-storage-demo \
  --min-tls-version TLS1_2
```

## 8️⃣ Authentication Using Azure AD (Best Practice)

Assign role to yourself:

```bash
az role assignment create \
  --assignee $(az ad signed-in-user show --query id -o tsv) \
  --role "Storage Blob Data Owner" \
  --scope $(az storage account show \
    --name $STORAGE \
    --resource-group rg-storage-demo \
    --query id -o tsv)
```

✔️ Now you can access storage **without keys**

## 1️⃣1️⃣ Cost Model (Very Important)

You pay for:

* Storage used (GB)
* Transactions (read/write)
* Data egress (outbound)
* Redundancy level

💡 Blob/File pricing depends on **storage account tier**

## 1️⃣2️⃣ Deleting Storage Account (Cleanup)

```bash
az storage account delete \
  --name $STORAGE \
  --resource-group rg-storage-demo \
  --yes
```

⚠️ **Deletes EVERYTHING inside it**
