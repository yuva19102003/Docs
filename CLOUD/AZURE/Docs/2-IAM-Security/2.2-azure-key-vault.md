# 🔐 Azure Key Vault – Full Creation + Access Workflows

---

## 🔴 STEP 0: COMMON SETUP (ONCE)

### Prerequisites

* Azure Subscription
* Azure CLI installed
* Logged in to Azure

```bash
az login
az account set --subscription <SUBSCRIPTION_ID>
```

---

## 1️⃣ CREATE RESOURCE GROUP

```bash
az group create \
  --name RaidenLabs-Website \
  --location centralindia
```

---

## 2️⃣ CREATE AZURE KEY VAULT (RBAC MODE)

```bash
az keyvault create \
  --name raidenlabs-kv \
  --resource-group RaidenLabs-Website \
  --location centralindia \
  --enable-rbac-authorization true
```

✔ Uses **Azure RBAC** (recommended)
✔ Centralized permission model

---

## 3️⃣ CREATE A SECRET

```bash
az keyvault secret set \
  --vault-name raidenlabs-kv \
  --name DB-CONNECTION-STRING \
  --value "mongodb://raidenUser:p@ssW0rd123@db01.mongo.cloud:27017/raidenDB"
```

### Workflow

```
Azure AD User
 → Assigned KV Role
 → Azure Portal
 → Read Secret
```

### Steps

1. Assign role:

```bash
az role assignment create \
  --assignee <USER_OBJECT_ID> \
  --role "Key Vault Secrets Officer" \
  --scope <KEY_VAULT_ID>
```

2. Portal → Key Vault → Secrets → Show value

# 🔐 Azure Key Vault – Delete & Cleanup Commands

## 1️⃣ Delete a Secret (Soft-Deleted)

```bash
az keyvault secret delete \
  --vault-name azure-SAL-kv \
  --name DB-CONNECTION-STRING
```

### Verify deleted secrets

```bash
az keyvault secret list-deleted \
  --vault-name azure-SAL-kv \
  -o table
```

---

## ♻️ Recover a Deleted Secret (If Needed)

```bash
az keyvault secret recover \
  --vault-name azure-SAL-kv \
  --name DB-CONNECTION-STRING
```

---

## 🔥 Permanently Delete (Purge) a Secret

```bash
az keyvault secret purge \
  --vault-name azure-SAL-kv \
  --name DB-CONNECTION-STRING
```

⚠️ **Irreversible**
⚠️ Requires **Purge** permission

---

## 2️⃣ Delete the Key Vault (Soft-Deleted)

```bash
az keyvault delete \
  --name azure-SAL-kv \
  --resource-group azure-solution-architect-labs
```

This **soft-deletes** the vault.

---

## ♻️ Recover the Deleted Key Vault

```bash
az keyvault recover \
  --name azure-SAL-kv
```

---

## 🔥 Permanently Delete (Purge) the Key Vault

```bash
az keyvault purge \
  --name azure-SAL-kv \
  --location eastus
```

⚠️ Required when:

* Re-creating a vault with the **same name**
* Cleaning up labs

---

## 🧠 VERY IMPORTANT NOTES

### Soft Delete Rules

* Always enabled
* Applies to **secrets, keys, certs, and vaults**

### Purge Protection

* ❌ Disabled → Purge allowed
* ✅ Enabled → Purge blocked until retention ends
