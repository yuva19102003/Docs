
# ✅ **Create a User in Azure (Very Simple Guide)**

> **Goal:** Your company already has an Azure account. You want your own login/user inside that tenant.

⚠️ **Important:**
You must have **Azure AD / Entra ID admin permissions** (Global Admin or User Admin) to create a user.
If you don’t have that access, **an admin must do these steps** for you.

---

# 🟦 **STEP–BY–STEP: Create a User in Microsoft Entra ID (Azure AD)**

### 1️⃣ **Login to Azure Portal**

Go to:
👉 [https://portal.azure.com/](https://portal.azure.com/)

---

### 2️⃣ **Open “Microsoft Entra ID”**

From the left menu search/select:
**Microsoft Entra ID**
(Old name: Azure Active Directory)

---

### 3️⃣ **Open “Users”**

Inside Entra ID →
Click **Users**

---

### 4️⃣ **Click “+ New User”**

Top bar →
Click **+ New user** → choose **Create new user**

You will see a form.

---

### 5️⃣ **Fill the Required Details**

| Field         | What to enter                                                               |
| ------------- | --------------------------------------------------------------------------- |
| **User name** | Example: `yourname@companydomain.onmicrosoft.com` or `yourname@company.com` |
| **Name**      | Your full name                                                              |
| **Password**  | Azure will generate or you can set manually                                 |

📌 After creation, you will **receive the username + temporary password**.

---

### 6️⃣ **Assign a Role (optional but required for admin/dev work)**

Go to the created user →
Left side: **Assigned roles** →
Click **Add assignments**

Choose one of these roles:

### 🔹 **If you only need basic access**

* **User**

### 🔹 **If you need to create/manage resources**

* **Contributor** (recommended)

### 🔹 **If you need to manage users**

* **User Administrator**

### 🔹 **If you need full control**

* **Global Administrator** (only if your company approves)

---

### 7️⃣ **Assign Azure Subscription Permissions**

Creating a user is NOT enough.
You must also be added to **the Azure subscription** where resources exist.

Steps:

1. Go to **Subscriptions**
2. Select your company subscription
3. Go to **Access control (IAM)**
4. Click **Add → Add role assignment**
5. Choose role:

   * **Contributor** (most common for DevOps / Developers)
   * **Reader** (if only viewing)
6. Select your created user
7. Click **Save**

---

# 🎉 **DONE — You Now Have Your Own Azure User**

You can now login using:

🔑 **Email/Username:** `yourname@company.com`
🔑 **Temporary password:** given by Azure
(You must change it on first login)
