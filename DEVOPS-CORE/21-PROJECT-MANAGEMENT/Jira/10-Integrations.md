# Jira Integrations

## Popular Integrations

### Development Tools

**GitHub**
- Link commits to issues
- View pull requests in Jira
- Automatic status transitions

**GitLab**
- Similar to GitHub integration
- Merge request tracking

**Bitbucket**
- Native Atlassian integration
- Branch and PR visibility

### CI/CD Tools

**Jenkins**
- Build status in Jira
- Deployment tracking
- Automated transitions

**GitHub Actions**
- Workflow status
- Deployment information

**GitLab CI**
- Pipeline visibility
- Build notifications

### Communication Tools

**Slack**
- Issue notifications
- Create issues from Slack
- Status updates

**Microsoft Teams**
- Similar to Slack integration
- Team collaboration

### Monitoring Tools

**Datadog**
- Link incidents to issues
- Performance metrics

**PagerDuty**
- Incident management
- On-call integration

## Setting Up Integrations

```
1. Jira Settings → Apps
2. Find integration in Marketplace
3. Click "Get it now"
4. Configure settings
5. Authenticate with service
6. Test integration
```

## Integration Best Practices

- Use webhooks for real-time updates
- Configure only needed integrations
- Set up proper permissions
- Monitor integration health
- Document integration workflows
