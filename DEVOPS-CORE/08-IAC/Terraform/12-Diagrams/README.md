# 📊 Terraform Architecture Diagrams

## Terraform Core Workflow

```
┌─────────────────────────────────────────────────────────────────┐
│                    TERRAFORM WORKFLOW                           │
└─────────────────────────────────────────────────────────────────┘

    Developer                Terraform Core           Cloud Provider
        │                          │                         │
        │  1. Write .tf files      │                         │
        │─────────────────────────>│                         │
        │                          │                         │
        │  2. terraform init       │                         │
        │─────────────────────────>│                         │
        │                          │  Download Providers     │
        │                          │<────────────────────────│
        │                          │                         │
        │  3. terraform plan       │                         │
        │─────────────────────────>│                         │
        │                          │  Read Current State     │
        │                          │<───────────────────────>│
        │  <── Show Changes        │                         │
        │<─────────────────────────│                         │
        │                          │                         │
        │  4. terraform apply      │                         │
        │─────────────────────────>│                         │
        │                          │  Create/Update Resources│
        │                          │────────────────────────>│
        │                          │  <── Resource Created   │
        │                          │<────────────────────────│
        │                          │  Update State File      │
        │  <── Apply Complete      │                         │
        │<─────────────────────────│                         │
```

## Terraform State Management

```
┌─────────────────────────────────────────────────────────────────┐
│                    STATE MANAGEMENT                             │
└─────────────────────────────────────────────────────────────────┘

    Configuration Files          State File           Real Resources
    ┌──────────────┐          ┌──────────────┐      ┌──────────────┐
    │   main.tf    │          │ terraform.   │      │   AWS EC2    │
    │              │          │   tfstate    │      │   Instance   │
    │ resource     │   ┌─────>│              │<────>│              │
    │ "aws_        │   │      │ {            │      │  Running     │
    │ instance"    │   │      │   "id":      │      │              │
    │ "web" {      │   │      │   "i-123"    │      │  ID: i-123   │
    │   ami = ...  │   │      │   ...        │      │              │
    │ }            │   │      │ }            │      │              │
    └──────────────┘   │      └──────────────┘      └──────────────┘
                       │
                       │      Terraform reconciles:
                       │      1. What you want (config)
                       │      2. What Terraform knows (state)
                       └─────>3. What actually exists (cloud)
```

```
┌─────────────────────────────────────────────────────────────────┐
│              REMOTE STATE WITH LOCKING                          │

        │───────────────────>│                      │
        │                    │  Acquire Lock        │
        │                    │─────────────────────>│

        │                    │                      │

        │                    │─────────────────────>│
        │                    │                      │
    Developer B              │                      │
        │                    │                      │
        │  terraform apply   │                      │
        │───────────────────>│                      │
        │                    │  Try Acquire Lock    │
```
